# Security policy

## Supported versions

The package major version tracks the Laravel major version.

| Version | Laravel | Security fixes |
| --- | --- | --- |
| 13.x | 13 | Yes |
| 12.x | 12 | Yes |
| 11.x and older | 11 and older | No |

`master` is the current major version and receives all fixes. `12.x` receives security fixes only. See [Version compatibility](https://nwidart.github.io/laravel-modules/upgrading/compatibility/).

## Report a vulnerability

Use the [private report form](https://github.com/nWidart/laravel-modules/security/advisories/new). You can also open it from the repository's Security tab with "Report a vulnerability".

Do not open a public issue, discussion or pull request for a vulnerability.

Include:

- The affected `nwidart/laravel-modules` version.
- Your Laravel and PHP versions.
- Steps to reproduce the problem.
- The impact: what an attacker can do.

## What happens next

The maintainers confirm the report, fix the problem on the supported branches, publish a release and publish a GitHub security advisory.
