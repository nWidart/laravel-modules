---
title: Community packages
description: Third-party packages that build on laravel-modules, with what each does and when it was last updated.
---

These packages work with `nwidart/laravel-modules`. Their authors maintain them. This project does not maintain, test or support them, and a package may not support every version of Laravel Modules. Check its repository for the versions it supports.

The list holds packages that exist, are not archived, and are named in this project's README or relevant to a feature it lacks. "Last push" is the year of the latest push to the default branch at the time of writing.

| Package | What it does | Last push |
| --- | --- | --- |
| [`mhmiton/laravel-modules-livewire`](https://github.com/mhmiton/laravel-modules-livewire) | Registers Livewire components that live in modules. Laravel Modules itself has no Livewire integration. | 2026 |
| [`dcblogdev/laravel-module-generator`](https://github.com/dcblogdev/laravel-module-generator) | Generates a Laravel Modules module from a template. | 2026 |

To add a package to this list, open a pull request that changes this page. See [Contribute and get help](/laravel-modules/ecosystem/contributing-and-support/).
