---
title: Seed a module with factories and seeders
description: Generate a factory and a seeder in a module, call them from the module database seeder, and run them with module:seed.
---

import { Steps } from '@astrojs/starlight/components';

To populate the `posts` table of the `Blog` module with test data, define a factory, call it from a seeder, and run `module:seed`. You need the `Post` model and factory from [Add Eloquent models to a module](/laravel-modules/guides/database/models/) and the migrated `posts` table.

`module:make` already generated `Modules/Blog/database/seeders/BlogDatabaseSeeder.php` with an empty `run()` method.

<Steps>

1. Define the factory. If you do not have one yet, generate `Modules/Blog/database/factories/PostFactory.php` with `php artisan module:make-factory Post Blog`.

   ```php title="Modules/Blog/database/factories/PostFactory.php"
   public function definition(): array
   {
       return [
           'title' => fake()->sentence(),
           'body' => fake()->paragraph(),
       ];
   }
   ```

2. Generate a seeder. The command appends `Seeder` automatically.

   ```bash
   php artisan module:make-seed Post Blog
   ```

   This creates `Modules/Blog/database/seeders/PostSeeder.php`. Add your factory call to `run()`:

   ```php title="Modules/Blog/database/seeders/PostSeeder.php"
   <?php

   namespace Modules\Blog\Database\Seeders;

   use Illuminate\Database\Seeder;
   use Modules\Blog\Models\Post;

   class PostSeeder extends Seeder
   {
       public function run(): void
       {
           Post::factory()->count(3)->create();
       }
   }
   ```

3. Call `PostSeeder` from the module's main database seeder.

   ```php title="Modules/Blog/database/seeders/BlogDatabaseSeeder.php"
   <?php

   namespace Modules\Blog\Database\Seeders;

   use Illuminate\Database\Seeder;

   class BlogDatabaseSeeder extends Seeder
   {
       public function run(): void
       {
           $this->call([PostSeeder::class]);
       }
   }
   ```

4. Run the module seeder.

   ```bash
   php artisan module:seed Blog
   ```

   ```text
      INFO  Seeding module ...

     Seeding Blog Module ......................................

      INFO  Seeding database.

     Modules\Blog\Database\Seeders\BlogDatabaseSeeder ............... RUNNING
     Modules\Blog\Database\Seeders\PostSeeder ....................... RUNNING
     Modules\Blog\Database\Seeders\PostSeeder ................... <time> DONE

     Modules\Blog\Database\Seeders\BlogDatabaseSeeder ............ <time> DONE

      INFO  Module [Blog] seeded.
   ```

   If seeding fails or you decline the production confirmation, the command prints an error and exits with status `1`.

5. Check the result.

   ```bash
   php artisan tinker --execute="echo Modules\Blog\Models\Post::count();"
   ```

   The count increases by 3 on each run (starting at `3` on an empty table).

</Steps>

## Run one seeder

Pass `--class` with a class in the module's seeder namespace to run a single seeder:

```bash
php artisan module:seed Blog --class=PostSeeder
```

## Seed after migrating

Add `--seed` to `module:migrate` to seed the module right after migrating:

```bash
php artisan module:migrate Blog --seed
```

## Seed modules with `db:seed`

Call the module's main seeder from `database/seeders/DatabaseSeeder.php` to include it in `php artisan db:seed`:

```php title="database/seeders/DatabaseSeeder.php"
public function run(): void
{
    $this->call([
        \Modules\Blog\Database\Seeders\BlogDatabaseSeeder::class,
    ]);
}
```
