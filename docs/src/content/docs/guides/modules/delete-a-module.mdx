title: Delete a module

---

To remove the module `Blog` from the application, delete its folder with `module:delete`. The command also removes the module from the activator.

<Steps>

1. If the module ran migrations, roll them back first. After the module is deleted, its migration files are gone and you cannot roll them back.

   ```bash
   php artisan module:migrate-reset Blog
   ```

2. Delete the module.

   ```bash
   php artisan module:delete Blog
   ```

   The command asks `Warning: Do you want to remove the module?` in every environment. To skip the question, add `--force`:

   ```bash
   php artisan module:delete Blog --force
   ```

   To delete several modules, list the names. To delete all of them, use `--all`.

3. Regenerate the autoloader, so Composer forgets the classes of the module.

   ```bash
   composer dump-autoload
   ```

4. Check the result.

   ```bash
   php artisan module:list
   ```

   `Blog` is no longer in the list, its folder `Modules/Blog` is gone, and `modules_statuses.json` has no `Blog` entry.

</Steps>

The command removes the folder and the status entry only. Files you copied out of the module stay: assets published with `module:publish` (in `public/modules/blog`), migrations published with `module:publish-migration` and translations published with `module:publish-translation`. Delete them yourself.
