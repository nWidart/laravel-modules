To load modules stored outside `paths.modules` (for example in `plugins/`), add those folders to `scan.paths`. Each folder holds modules as subdirectories, such as `plugins/Acme/module.json`.

## Scan extra folders from the config

<Steps>

1. Publish `config/modules.php` if you have not already.

   ```bash
   php artisan vendor:publish --provider="Nwidart\Modules\LaravelModulesServiceProvider" --tag=config
   ```

2. Enable scanning and list the extra folders.

   ```php title="config/modules.php"
   'scan' => [
       'enabled' => true,
       'paths' => [
           base_path('plugins'),
       ],
   ],
   ```

   The package appends `/*` to any path that does not already end with `/*`, then looks for `module.json` inside each match. `base_path('plugins')` matches `plugins/Acme/module.json`, while the default `base_path('vendor/*/*')` matches `vendor/acme/blog/module.json`.

3. Add the folder to `extra.merge-plugin.include` in `composer.json` and rebuild the autoloader.

   ```json title="composer.json"
   "extra": {
       "merge-plugin": {
           "include": [
               "Modules/*/composer.json",
               "plugins/*/composer.json"
           ]
       }
   }
   ```

   ```bash
   composer dump-autoload
   ```

   Autoload the module before enabling it. Enabling a module whose provider class cannot autoload breaks every `artisan` command with a class-not-found error.

4. Enable the discovered module. Newly scanned modules start disabled.

   ```bash
   php artisan module:enable Acme
   ```

5. Check the result.

   ```bash
   php artisan module:list
   ```

   `Acme` appears with its path (`plugins/Acme [0]`).

</Steps>

## Add a folder at runtime

Call `Module::addLocation()` to expose an extra folder at runtime:

```php title="app/Providers/AppServiceProvider.php"
use Nwidart\Modules\Facades\Module;

public function register(): void
{
    Module::addLocation(base_path('plugins'));
}
```

`addLocation()` makes modules visible to `Module::all()`, `Module::find()`, and `module:list`. It does not register their service providers, because module providers load before application providers run. Use `scan.paths` to boot providers from extra folders.
