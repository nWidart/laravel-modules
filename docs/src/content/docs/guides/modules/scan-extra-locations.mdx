To use modules that live outside `paths.modules`, for example in `plugins/`, tell the package which extra folders to scan. A folder you add holds the modules as sub-folders: `plugins/Acme/module.json` is the module `Acme`.

## Scan extra folders from the config

<Steps>

1. Publish the config file, if you have not.

   ```bash
   php artisan vendor:publish --provider="Nwidart\Modules\LaravelModulesServiceProvider" --tag=config
   ```

2. Enable the scan and list the folders.

   ```php title="config/modules.php"
   'scan' => [
       'enabled' => true,
       'paths' => [
           base_path('plugins'),
       ],
   ],
   ```

   The package adds `/*` to an entry that does not end with `/*`, then reads `<entry>/module.json`. `base_path('plugins')` becomes `plugins/*` and finds `plugins/Acme/module.json`: the entry is the folder that holds the modules as sub-folders. An entry that already ends with `/*` stays as it is. The default entry, `base_path('vendor/*/*')`, finds `vendor/acme/blog/module.json`.

3. Make Composer autoload the modules in the folder. Add the folder to `extra.merge-plugin.include` in the `composer.json` of the application, then regenerate the autoloader.

   ```json title="composer.json"
   "extra": {
       "merge-plugin": {
           "include": [
               "Modules/*/composer.json",
               "plugins/*/composer.json"
           ]
       }
   }
   ```

   ```bash
   composer dump-autoload
   ```

   An enabled module whose provider class cannot be loaded stops every `artisan` command, with `Class "Modules\Acme\Providers\AcmeServiceProvider" not found`. Autoload the module before you enable it.

4. Enable each new module. A module the package finds has no status yet, so it counts as disabled.

   ```bash
   php artisan module:enable Acme
   ```

5. Check the result.

   ```bash
   php artisan module:list
   ```

   `Acme` is in the list with its path, for example `plugins/Acme [0]`.

</Steps>

The package registers the providers of the modules in these folders like those of any other module. It does not autoload their classes: step 3 does that.

## Add a folder at runtime

To add a folder from code, call `Module::addLocation()`.

```php title="app/Providers/AppServiceProvider.php"
use Nwidart\Modules\Facades\Module;

public function register(): void
{
    Module::addLocation(base_path('plugins'));
}
```

`addLocation()` makes the modules in the folder visible to `Module::all()`, `Module::find()` and `module:list`. It does not register their providers: the package registers module providers before your application providers run. To load providers from an extra folder, use `scan.paths`.
